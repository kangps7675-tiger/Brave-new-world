# 시크릿 설정 가이드 (처음부터 끝까지)

배포 전에 비밀번호 2개를 만들어서 정해진 자리에 넣는 작업입니다.
**총 15분**이면 끝납니다. 순서대로만 따라 하세요.

---

## 0. 먼저 — 이게 뭐고 왜 하는가

### 시크릿 = 서버끼리 쓰는 비밀번호

이 프로젝트에는 서버가 **2개** 있습니다.

```
┌─────────────────────┐          ┌─────────────────────┐
│   Cron 로봇 서버      │  ───▶   │    웹사이트 서버      │
│ (10분마다 자동 실행)   │  "데이터  │  (사람들이 보는 지도)  │
│  conflict-view-      │  갱신해!" │  confilct-view      │
│  ingest             │          │                     │
└─────────────────────┘          └─────────────────────┘
```

Cron 로봇이 웹사이트 서버한테 "데이터 갱신해!"라고 명령을 보냅니다.
그런데 여기에 **비밀번호가 없으면 아무나 그 명령을 보낼 수 있습니다.**

실제로 그러면 이런 일이 생깁니다.

- 아무나 전체 사용자에게 **가짜 공습경보 푸시 알림**을 보낼 수 있음
- 아무나 유료 API(NASA, 위성 추적 등)를 마구 호출해서 **요금 폭탄**을 만들 수 있음

그래서 비밀번호를 걸어두는 겁니다.

### 만들 비밀번호 2개

| 이름 | 무슨 자물쇠인가 |
|---|---|
| `INGEST_CRON_SECRET` | Cron 로봇 ↔ 웹사이트 서버 사이의 자물쇠 |
| `VIINA_RENDER_GATE_SECRET` | 우크라이나 전선 지도 데이터 무단 복사 방지 자물쇠 |

### ⚠️ 가장 헷갈리는 부분 (미리 읽어두세요)

**이건 어디서 "발급받는" 게 아닙니다.**

NASA 키나 Anthropic 키는 그 회사 홈페이지에 가입해서 받아옵니다.
하지만 이 2개는 **내가 아무 무작위 글자나 만들어서 정하면 그게 곧 비밀번호**입니다.
가입할 사이트도, 신청할 곳도 없습니다.

집 현관 도어락 비밀번호를 내가 정하는 것과 똑같습니다.
조건은 하나 — **아무도 못 맞출 만큼 길고 무작위일 것.**

## 4단계 — 첫 번째 비밀번호 넣기 · Cron 로봇 쪽 (2분)

```powershell
npx wrangler secret put INGEST_CRON_SECRET -c wrangler.ingest.toml
```

`Enter` 를 누르면 이렇게 물어봅니다:

```
✔ Enter a secret value: ›
```

여기에 메모장의 **`INGEST_CRON_SECRET` 값**을 붙여넣고 `Enter`

> 🤔 **붙여넣었는데 화면에 아무것도 안 보여요!**
> 정상입니다. 비밀번호라서 일부러 안 보여줍니다. 그냥 `Enter` 치세요.

성공하면:

```
✨ Success! Uploaded secret INGEST_CRON_SECRET
```

## 5단계 — 같은 비밀번호를 웹사이트 서버에도 (2분)

### ❗ 여기가 가장 많이 틀리는 곳입니다

4단계와 **똑같은 값**을 넣어야 합니다. 새로 만들면 안 됩니다.

이유: Cron 로봇이 "이거 내 비밀번호야" 하고 보내면, 웹사이트 서버가 자기가 아는 값과
비교해서 맞는지 확인합니다. **두 값이 같아야만 통과**합니다.

```
Cron 로봇:  "비밀번호는 EXAMPLE_ONLY_... 야"
                    │
                    ▼
웹사이트 서버: "내가 아는 것도 EXAMPLE_ONLY_... → 통과 ✅"
              "내가 아는 건 다른값... → 거부 ❌ (401 에러)"
```

명령어에서 `-c wrangler.ingest.toml` 이 **빠진 것**에 주의하세요.

```powershell
npx wrangler secret put INGEST_CRON_SECRET
```

메모장에서 **4단계와 같은 값**을 붙여넣고 `Enter`

## 7단계 — 내 컴퓨터에서 개발할 때 쓸 파일 만들기 (2분)

여기까지는 **인터넷에 올라간 서버** 설정이었습니다.
이제 **내 컴퓨터에서 `npm run dev` 로 개발할 때** 쓸 파일을 만듭니다.

아래를 통째로 복사해서 붙여넣고 `Enter`
(`여기에_붙여넣기` 부분만 메모장 값으로 바꾸세요)

```powershell
@"
NEXTJS_ENV=development
INGEST_CRON_SECRET=여기에_INGEST_CRON_SECRET_값_붙여넣기
"@ | Out-File -FilePath .dev.vars -Encoding utf8
```

**확인:**

```powershell
type .dev.vars
```

방금 넣은 내용이 보이면 성공입니다.

> 이 파일은 `.gitignore` 에 등록되어 있어서 GitHub에 안 올라갑니다. 안심하세요.

> 그래서 2단계에서 메모장에 저장하라고 한 겁니다.

## 문제가 생겼을 때

### `401 unauthorized` 가 뜬다

**십중팔구 4단계와 5단계의 값이 서로 다릅니다.**

해결: 메모장의 `INGEST_CRON_SECRET` 값으로 4·5단계를 **둘 다 다시** 실행하세요.
(같은 이름으로 다시 넣으면 덮어쓰기 됩니다. 지울 필요 없습니다.)

### 메모장을 안 만들고 창을 닫아버렸다

값을 되찾을 방법은 없습니다. 하지만 괜찮습니다 —
**2단계부터 새 값으로 처음부터 다시** 하면 됩니다. 아무 문제 없습니다.

### `VIINA_RENDER_GATE_SECRET is not configured` 에러

6단계를 건너뛰었거나 실패한 겁니다. 6단계를 다시 하세요.

### `npx` 또는 `node` 를 찾을 수 없다고 나온다

Node.js가 안 깔려 있습니다. <https://nodejs.org> 에서 **LTS** 버전을 받아 설치하고,
**터미널을 껐다 켠 뒤** 1단계부터 다시 하세요.

### `wrangler login` 에서 브라우저가 안 열린다

터미널에 나온 `https://dash.cloudflare.com/...` 주소를 복사해서
브라우저 주소창에 직접 붙여넣으세요.
