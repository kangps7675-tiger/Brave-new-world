# 참고 사이트 × 멋진 신세계 — 쓰기 쉬운 UX 가이드

**제품:** 멋진 신세계 / Brave New World  
**참고하는 사이트:** [warwatch.world](https://warwatch.world) (아래에서는 「참고 사이트」라고만 부름)  
**이 문서가 하는 일:** 참고 사이트처럼 **「지금 뭘 하면 되는지」가 메뉴에 보이는** 느낌을, 우리 지구본 화면 위에 표지판으로만 옮긴다.  
**하지 않는 일:** 남 코드·광고 배치·납작한 점선 지도를 베끼지 않는다. 표지판만 빌리고, 지구본·속보 카드·입체 지도는 우리 것이다.

---

## 1. 쉬운 말로 먼저

참고 사이트는 **방 이름 = 할 일**이라, 처음 온 사람도 메뉴만 보고 길을 안다.  
우리 웹은 **한 관측실에 도구가 전부** 있어서, 만드는 사람은 편하고 쓰는 사람은 「뭘 누르지?」가 먼저다.

고치는 방향은 방을 다섯 개로 나누는 게 아니다.  
**입구에 「전선 볼래 / 실시간 볼래 / 시장 볼래 / 물어볼래」 표지판**을 다는 것이다.

우리가 부족한 것은 기능이 아니라 **「오늘은 이것만 보면 돼」라는 안전장치**다.

| | 참고 사이트 | 멋진 신세계 (우리) |
|--|-------------|-------------------|
| 비유 | 교실 세계지도 + 뉴스 게시판 | 암실 관측대 + 입체 지구본 |
| 길 찾기 | 메뉴 = 할 일 | 한 화면에 도구가 많음 |
| 초보 경험 | 메뉴만 보고 고름 | 기능은 많은데 입구 말이 어려움 |
| 빌릴 것 | 표지판·목적 이름·첫 질문 | — |
| 지킬 것 | — | 지구본·속보 카드·실시간 전선·시장·물류 |

---

## 2. 쓰기 쉽게 만드는 태도 (항상 이게 먼저)

1. **할 일 먼저** — 도구를 늘어놓지 말고 「오늘은 이것만」  
2. **사람 말투** — 「지정학/지경학」보다 「분쟁·전선 / 시장·물류 / 실시간 입체」  
3. **한 화면, 한 목적** — 한꺼번에 다 켜지 말 것  
4. **다음 문** — 속보를 읽었으면 → 분쟁 지도 / 시장·물류로 이어 주기  
5. **안 되면 안 보이기** — 눌러도 아무 일도 없는 버튼 대신 「묻기」처럼 되는 것  
6. **질문은 짧게** — 긴 대화창보다 묻기·한 줄 해석  
7. **보는 것이지, 사는 것이 아님** (시세는 참고용)  
8. **읽는 순서** — 왼쪽→오른쪽, 위→아래. 상단은  
   `메뉴 → 보기 고르기 → 검색·묻기 → 보조 도구 → 시계·숫자`.  
   좁은 화면에서는 위=중요한 보기, 아래=덜 급한 도구.

**이미 반영한 것:** 보기 이름 · 목적 카드 · 속보 다음 문 · 입체 지도에서 「묻기」 · 휴대폰 탭 말투 · 상단 읽기 순서.  
**추가 반영:** 첫 안내 투어는 조금 늦게 · 묻기 추천 질문·하루 횟수 제한 · 없는 「주요전장」 안내 문구 제거.

## 3. 참고 사이트가 유저에게 주는 경험

### 3.1 한 줄로

세계 분쟁을 **지도 → 뉴스 → 물어보기 → 시장** 순으로 훑는 대중용 사이트.

### 3.2 「방」= 「할 일」

| 메뉴에 보이는 말 | 유저가 하는 일 |
|------------------|----------------|
| 지도 | 어디서 무슨 일이 있는지 한눈에 |
| 진행 중 분쟁 | 목록으로 훑고 골라 보기 |
| 국가 위험도 | 이 나라는 얼마나 위험한가 |
| 물어보기 | 말로 질문하기 |
| 시장 | 유가·금·물류에 미치는 영향 |

맨 위 메뉴에도 위 다섯이 그대로 보인다. (시계·밝은/어두운 화면은 보조)

### 3.3 심각도 색 (참고)

| 단계 | 색 |
|------|-----|
| 진행 중 전쟁 | 빨강 |
| 고조 | 주황 |
| 불안정 | 노랑 |
| 안정 | 초록 |

### 3.4 가져올 것 / 안 가져올 것

**가져올 것**

1. 메뉴 글자 = 유저가 하려는 일  
2. 한 번에 하나 — 들어가면 그 목적만  
3. 초보용 「오늘은 이것만」

**안 가져올 것**

- 납작한 점·선 지도로 우리 지도를 바꾸기  
- 광고가 화면의 주인공이 되는 배치  
- 페이지를 잘게 쪼개는 것 자체  
- 밋밋한 기본 글씨·이모지만 쓰는 분위기  
- 가짜 광고 칸  

**따라가지 말 약점:** 광고가 맨 앞 · 언어 선택이 안내와 다름 · 깨진 링크 · 질문 도우미 이름 혼란 · 속보 문구가 특정 분쟁에만 고정

## 4. 우리 제품 — 유저가 겪는 흐름 (지금)

### 4.1 처음 들어왔을 때

1. 잠깐 로딩 · 이 브라우저가 입체 지도를 돌릴 수 있는지 확인  
2. **언어만 고름** (한국어 / English) — 필수  
3. 곧바로 지구본 + 위쪽 도구가 **전부** 보임  
4. 「무엇을 볼까요?」 같은 **목적 고르기**는 예전에 없었고, 지금은 목적 카드로 보완  
5. 긴 환영·주의·출처 안내는 첫 진입에서 빼 둠  
6. 짧은 안내 뒤, **원할 때만** 둘러보기 투어 (자동으로 전부 돌리지 않음)

### 4.2 화면에서 보이는 것

```
홈
├─ 언어 선택 (첫 방문)
├─ 목적 카드 — 「무엇을 볼까요?」(한 번 고르면 다음에 생략, 메뉴에서 다시 열 수 있음)
├─ 위쪽
│    ├─ 메뉴
│    ├─ 보기 고르기: 분쟁·전선 | 실시간 입체 | 시장·물류
│    ├─ 검색 · 묻기 · 영토 분쟁 · 역사 지도 · 주요 지역
│    └─ 시계 · 숫자 지표
├─ 가운데: 지구본 / 입체 지도
├─ 아래: 뉴스 요약 → 펼치면 더 읽기
├─ 실시간 입체일 때: 전선 속보 → 속보 카드
└─ 도움 말풍선 · 「지도에 더 보이기」 설정 등

따로 있는 페이지
├─ 병목 해역(좁은 뱃길) 자세히
├─ 미사일 추적
└─ 관리자·내부용
```

### 4.3 보기 세 가지

| 유저에게 보이는 말 | 안에서 하는 일 |
|--------------------|----------------|
| 분쟁·전선 | 전선·진영·뉴스, 아래쪽 소식 |
| 실시간 입체 | 입체 지도 · 전선 속보 · 비행기·배 · 시세 |
| 시장·물류 | 병목 해역·뱃길·시세 · 시장 목록 |

- **역사**는 세 보기 밖 → 「역사 지도」로만  
- 실시간 입체에서 「지도에 더 보이기」가 비어 있던 자리는 정리하거나 실제로 연결할 대상

### 4.4 휴대폰

탭 이름: **지정학 / 증시 / 지경학** — 컴퓨터 화면과 말이 조금 다름. 가능하면 같은 「할 일」 말로 맞출 것.

### 4.5 전선 속보가 올 때 (실시간 입체)

```
새 속보가 있으면 (약 1분마다 확인)
  → 잠깐 알림 ("전선 속보")
  → 아직 안 읽음 표시
  → 속보 카드 (이전/다음 · 그 위치로 가기)
  → 지도에 핀 · 누가 잡고 있는 구역 표시
```

### 4.6 아직 헷갈리기 쉬운 지점

1. 큰 버튼이 **분야 이름**이면, 초보는 **할 일 이름**(분쟁 목록·물어보기)을 못 찾음  
2. 「목록 보기 / 물어보기 / 시장」이 검색·묻기·아래 펼침·주요 지역에 **흩어져** 있음  
3. ~~없는 「주요전장」을 투어가 가리킴~~ → 정리 완료 (2026-09-30)  
4. 속보·미사일·일부 장면은 메뉴 안쪽 깊숙함  
5. 언어만 고르고 **목적 없이** 도구가 전부 뜨던 구멍 → 목적 카드로 보완  
6. 병목 해역·미사일 페이지는 메인 메뉴와 연결이 약함

## 5. 「할 일」 ↔ 우리에 이미 있는 것

| 유저가 하려는 일 | 우리에 있는 곳 | 아직 부족한 점 |
|------------------|----------------|----------------|
| 지도로 한눈에 | 홈 지구본 | 선택지가 너무 많음 |
| 분쟁 목록 | 분쟁·전선 보기 + 아래 뉴스 + 주요 지역 | 「목록」이라는 입구·전용 보기가 약함 |
| 이 나라 위험도 | 주요 지역·나라 포커스 | **한 장 요약(점수)** 없음 |
| 물어보기 | 「묻기」 | 예전에 검색 옆 작은 자리였음 → 크게 올리는 중 |
| 시장·물류 | 시장·물류 보기 + 아래 목록 | 이름이 초보에게 멀었음 → 쉬운 보조 말로 보완 |

→ **페이지 다섯 개를 새로 만들지 말고**, 같은 목적에 **이름 붙인 표지판**만 기존 화면 위에 올린다.

## 6. 맞춤 제안 (무엇을 / 왜)

### 원칙

- 화면을 여러 사이트로 쪼개지 말 것 — 한 지구본이 강점  
- 위 세 보기 고르기는 유지 — 이미 「무엇을 볼지」 역할  
- 예전에 쓰던 「꾸러미 고르기」처럼 제작자 말투로 돌아가지 말 것  
- 추가할 것은 **목적 표지판 한 겹**뿐  

### 우선순위

| 순위 | 유저가 느끼는 변화 | 왜 |
|------|-------------------|-----|
| 1 | 언어 다음 **목적 카드** ✅ | 첫 화면이 「조종석 전부」가 되지 않게 |
| 2 | 「묻기」를 크게 + 보기에 쉬운 보조 말 | 있는 기능을 「할 일」로 보이게 |
| 3 | 분쟁·전선에서 **진행 중 분쟁** 목록 느낌 | 목록 전용 사이트로 가지 않고도 같은 일 |
| 4 | 안내용어·빈 버튼 정리 | 「만든 사람만 아는 앱」 인상 제거 |
| 5 | 국가를 고르면 **위험도 한 장** | 참고 사이트 대비 실질 빈칸 |

### 먼저 — 목적 카드 ✅

언어 다음, 짧은 선택:

1. **전선·분쟁 보기**  
2. **입체로 실시간 보기**  
3. **시장·물류 보기**  
4. **물어보기**  
5. **그냥 둘러보기**  

한 번 고르면 다음에 생략. 메뉴 「무엇을 볼까요?」로 다시 열 수 있음.  
(배에 대한 표시를 처음부터 전부 켜는 것은 보류 — 데이터가 적어 유료 전환 예정)

### 다음 — 쉬운 보조 말 + 「묻기」크게

| 지금 쓰이는 말 | 초보에게 보이는 보조 말 |
|----------------|-------------------------|
| 지정학 | 분쟁·전선 |
| 3D 라이브 / 실시간 | 실시간 지도 |
| 지경학 | 시장·운송 |

안쪽 이름은 그대로 두고, **화면에 보이는 말만** 할 일에 가깝게.  
「묻기」는 검색 옆 작은 버튼이 아니라 **보기 고르기와 같은 급**.

### 그다음 — 「분쟁 목록」느낌

- 새 「분쟁만 보는 사이트」 만들지 말 것  
- 분쟁·전선에서 아래쪽을 **「진행 중 분쟁」** 중심으로, 또는 위쪽 「분쟁」을 누르면 목록이 열리고 지도와 이어지게  

### 나중 — 국가 위험도 한 장

- 나라/주요 지역 선택 → 점수·관련 전선·시장 한 줄  
- 표지판만으로는 안 채워짐 — 보여줄 내용 설계가 필요  
- 참고 사이트의 계기판을 베끼지 말고, 우리 속보 카드·유리 질감 톤  

### 정리 — 안내가 가리키는 것과 실제가 같게

- ~~없는 「주요전장」~~ → 정리 완료  
- 실시간 입체에서 빈 「지도에 더 보이기」 → 없애거나 실제로 연결  
- 미사일·병목 해역 → 메뉴·장면·「지도에 더 보이기」에 **한 줄**로 연결  

### 하지 말 것

- 참고 사이트처럼 페이지 여러 개로 이식  
- 광고가 앞서는 배치  
- 지구본을 포기하고 목록 사이트로 바꾸기  
- 예전 꾸러미 고르기 화면 부활

## 7. 실시간 입체 — 「할 일」한 줄

**한 문장:** 속보가 난 자리 → 그게 건드리는 뱃길·시세.

| 보여 줄 것 | 굳이 안 넣을 것 |
|------------|-----------------|
| 속보 → 알림 → 속보 카드 | 영토 분쟁 오래된 기록·역사 타임라인 밀기 |
| 속보 카드 안 시세 단추 1~3개 + 근처 병목 해역 | 지도 표시 전부 · 뉴스 전체 |
| 「위치로 가기」 | 매수·투자 버튼 |
| 병목 단추 → 물류 켜고 그곳으로 | 「예쁜 위성만 돌리기」 |

시세는 다른 사이트에서 **보기만** — 주문이 아님.

---

## 8. 매 화면 점검 질문

남 파일을 가져오지 말고, 아래만 묻는다.

> “처음 온 사람이, 메뉴(또는 첫 카드)만 보고도 ‘지금 할 일’을 고를 수 있나?”

1. 참고 메뉴 다섯 개를 종이에 적는다  
2. 우리에서 같은 일을 **지금 어디서** 하는지 적는다 (없으면 「숨음」)  
3. 숨은 것은 **이름 붙인 입구**만 만든다 (기능을 처음부터 다시 만들지 않음)  
4. 첫 방문: 목적 3~5개 → 이미 있는 보기 / 묻기 / 뉴스로 안내  

**한 줄:** 표지판만 빌리고, 지구본·속보 카드·입체 지도·시장·물류는 우리 건물 그대로.

## 9. 만드는 사람용 메모 (화면에 쓰지 말 것)

유저에게 보이는 문장에는 아래 이름을 쓰지 않는다.  
코드·파일만 찾을 때 여기 본다.

| 유저 말 (화면·이 문서 본문) | 코드·파일에서 쓰는 말 |

| 전선 속보 / 속보 카드 | LiveUA(Map), flash, parchment |
| 병목 해역 / 좁은 뱃길 | chokepoint, choke |
| 보기 고르기 | ViewModeSwitcher, lens, ViewerMode |
| 목적 카드 | PurposeJobOverlay, Job |
| 지도에 더 보이기 | layers |
| 아래 뉴스·목록 | sheet, intel |
| 주요 지역 | hub |
| 입체 지도 | Cesium, satellite 모드 |
