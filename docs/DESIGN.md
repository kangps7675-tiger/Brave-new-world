# 설계 의도 · 로드맵 (DESIGN)

> **이 문서와 README의 차이**
>
> | | 담는 것 | 시제 |
> |---|---|---|
> | `README.md` | **현재 코드가 실제로 하는 일** | "이렇게 되어 있다" |
> | `DESIGN.md` (이 문서) | **하기로 한 것 · 아직 안 한 것 · 왜** | "이렇게 할 것이다" |
>
> 두 문서를 분리한 이유는 실제 사고가 있었기 때문이다. UX 감사에서
> README ↔ 코드 불일치가 **2건** 확인됐고, 둘 다 *"이렇게 하기로 했다"*가
> *"이렇게 되어 있다"*로 적혀 있었다:
>
> 1. **레이어 적용 모델** — README "체크 즉시 반영" ↔ 코드 draft/confirm 다이얼로그
> 2. **ExplorationTabs** — README "지정학에서 숨김" ↔ 코드 양 모드 모두 마운트
>
> 이건 문서 관리 문제로 보이지만 실제로는 **UX 결정이 코드에 도달하지 못하고
> 중간에서 멈춘 것**이고, 그 상태가 문서에는 완료로 기록돼 있었다.
> 신규 합류자와 미래의 본인이 README를 믿고 잘못된 전제로 작업하게 된다.

---

## 규칙

1. **README에는 구현된 것만 쓴다.** "예정", "곧", "할 것"이 들어가면 이 문서로.
2. 결정을 내렸지만 아직 구현 전이면 아래 「미해결 결정」에 적는다.
3. 구현이 끝나면 이 문서에서 지우고 README로 옮긴다.
4. 문서를 고칠 때 코드도 같이 고칠 수 없으면, **문서에 현재 상태를 적는다.**

### ExplorationTabs 처리
- **README 서술:** 지정학에서 숨김

### 언어 게이트 제거
- **결정:** 진입에서 한/영을 묻지 않고 자동 감지 (완료: `detectDefaultLabelLanguage`)
- **미완:** `LanguageGateOverlay` · `EntryCautionOverlay`의 대형 한/영 버튼 제거
- **선행조건:** P1-5(i18n 마감) — 현재 `AnalysisPanel`·`BottomIntelStack`·`HoverNav`에 한국어 하드코딩이 남아 있다.
  영어권 홍보를 시작하기 전에는 반드시 선행할 것 (현재 홍보처가 국내라 blocking은 아님)

### 면책 고지 형태 변경
- **결정:** 전면 모달(`EntryCautionOverlay`) → 상시 하단 바
- **상태:** **법무 확인 대기.** 고지 기능은 유지하되 90초 점유를 0으로 만드는 것이 목적
- **구분:** A(데이터·저작권)·B(투자 권유 아님)·D(출처/Tier/가이드)는 약화하지 않는다. 법무에 물을 것은 **C(진입 고지)의 형태·시점·기록**뿐이다.
- **법무 확인 문항:** (1) 전면 클릭-스루가 필수인가, 상시 노출+출처 링크로도 충분한가 (2) 스킵 가능 고지는 고지로 인정되는가 (3) 소리 기본 OFF+언뮤트 넛지로 동의 흐름이 충분한가
- **엔지니어링 제약:** 변호사 답 전에 고지 문장 삭제·A/B 약화 금지. P0-2에서 주의창을 도메인으로 강등한 것은 **면책 폐기가 아님** — 고지가 어디로 옮겼는지(또는 임시로 DomainGate 링크로만 남았는지)를 이 문서에 유지한다.
- **현재 코드:** 첫 방문 기본 경로는 `domain` 게이트(주의/환영 풀스크린 스킵). 주의·환영은 DomainGate의 접힌 링크로 재열기 가능. LanguageGate는 자동 `markLangChoiceDone`으로 UI 미노출.

### 모바일 전략 (P2-3) — (b) 채택

**폰은 지구본을 마운트하지 않는다.** 성능상 옳은 결단이고 바꾸지 않는다.
깨진 건 제품이 아니라 **성장 루프**였다:

```
데스크톱 ShareView → ?scene=…
  → 폰이 연다 → 지구본 없음 → 장면을 못 봄 → 재공유 불가
```

> **폰에서의 약속은 「지도」가 아니라
> 「오늘의 긴장을 읽고, 공유된 장면을 이해할 수 있다」이다.**
> 지도 조작은 데스크톱·태블릿의 일.

| 단계 | 내용 | 상태 |
|---|---|---|
| A | `?scene=` → 폰 카드 랜딩 (지명·주제·GTI·CTA) | ✅ 완료 |
| B | OG/정적 프리뷰 이미지 (SNS 카드) | ⬜ |
| C | 필요할 때만 MapLibre 2D 최소 뷰. 3D·Deck 재도입은 금지에 가깝게 유지 | ⬜ 조건부 |

**성공 기준은 "폰에 지구본이 뜨는가"가 아니라 공유 링크 오픈 → 장면 이해 →
(가능하면) 재공유가 끊기지 않는가**다. `trackSceneOpen(surface)`로 잰다.

## 유지되는 원칙 (바꾸지 말 것)

- **모드 = 렌즈.** `ViewModeSwitcher` 하나로 레이어·nav·하단·fetch가 통째로 바뀐다. 이 축은 제품의 뼈대다.
- **GTI는 단일 기축 통화.** 랭킹·게이지·예측·사운드·브리핑은 전부 이 숫자의 파생상품.
- **자동 이동은 취소 가능해야 한다.** 자동 fly가 불안한 이유는 "움직여서"가 아니라 "멈출 수 없어서"다. 양피지 자동 펼침 금지는 계속 유지.
- **reduced-motion은 안전 항목.** 접근성 체크리스트가 아니라 건강 리스크로 다룬다.
- **온보딩은 예산제.** 세션당 2개. 새 넛지를 만들면 `onboardingBudget` 레지스트리에 등록할 것.
- **저장 키 버전을 올리지 않는다.** 레이어 추가는 `DEFAULT_LAYER_PREFS`에 기본값만 추가.

## 검증 스크립트

코드가 문서를 배신하지 않게 하는 자동 검사:

| 명령 | 무엇을 지키는가 |
|---|---|
| `npm run verify:reduced-motion` | 새 애니메이션이 무방비로 추가되지 않게 |
| `npm run verify:ui-tokens` | 임의 `text-[Npx]` · `z-[N]` 재발 방지 (기준선 0/0) |
| `npm run verify:i18n` | 핵심 4구역 한국어 누수 0 유지 |
| `npm run verify:syntax` | 대량 치환 직후 문법 파손 즉시 검출 |
| `npm test` | 온보딩 예산 · 첫 90초 · FPS 프로브 · 오버레이 큐 |

### `verify:syntax`가 생긴 이유

코드모드로 import를 삽입하다 여러 줄 `import {` 블록 **안에** 새 import를 꽂아
파일이 깨졌다. 그런데 당시 검증은 `grep`으로 "import가 존재하는가"만 봤기 때문에
**초록불이었다.** `tsc`가 잡았지만 전체 타입 그래프를 도느라 느리다.

> **존재 확인은 정확성 확인이 아니다.**
> 대량 치환 뒤에는 파싱 검사를 먼저 돌릴 것 — 몇 초면 끝난다.
