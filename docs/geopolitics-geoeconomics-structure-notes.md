# 지정학·지경학 구조 & 타깃 전략 — 정리

## 0. 제품 북극성 (2026-09 확정)

**한 문장:** 개인용 인텔리전스 터미널 — 전문가급 밀도의 지정학·지경학 OSINT를, 개인이 구독료 내고 쓸 수 있는 자리.

### 왜 이 프레임인가

- **블룸버그 터미널**은 연 ~2,900만원급 기관 전용. **팔란티어**는 개인용 SKU가 없음.
- “전문가급 밀도의 정보 도구를 개인이 쓴다”는 자리는 원래 비어 있었고, **TradingView**가 트레이딩 쪽에서 이미 증명함.
- **지정학·안보 쪽**에는 아직 그 자리를 채운 제품이 없음. 레이어 조합(지구본+전선+코리도+AIS+BRI/DFC 등) 자체가 희소 자산 → **B2B로 안 가도** 폭·밀도가 차별점.

### 이 프레임이 정리해 주는 것

| 주제 | 정리 |
|------|------|
| **밀도** | 버그가 아니라 컨셉. “애널리스트처럼 세상을 본다”는 내러티브가 있으면 레이어 많음 = 정체성. 지정학/지경학 이원 구조가 “하나로 묶기” 작업. |
| **게임 (GTS UP/DOWN·벙커)** | B2B와 어긋나지 않음. 페이퍼 트레이딩·예측은 Bloomberg/TradingView 문화권에서 자연스러움. 톤: “애널리스트도 자기 판단을 연습한다” — **감각 연습**. |
| **GTS 신뢰** | 게임이 재밌으려면 지수가 “진지하게 계산된 것”이라는 믿음 필요 → **출처·산출식·GTS 표기(IEP GTI와 구분)** 가 핵심 약속. (코드 반영 완료) |
| **가격 (나중)** | 광고형 무료보다 **프리미엄 개인 구독**(TradingView Pro처럼 월 커피값)이 자연스러움. |
| **출처 투명성** | 장식이 아니라 **없으면 안 되는** 조건. “개인용 팔란티어”를 자처하면서 출처를 숨기면 프레임 붕괴. |

### 타깃

- B2B OSINT SaaS ❌  
- **개인** — 뉴스 과다 섭취·지정학 관심·해외 거주·리서치 입문·인디 저널/크리에이터  
- Job: *오늘 세계가 더 시끄러운가 → 어디 → 왜* (GTS + 지도 + 출처)

## 1. 지금까지의 결정 순서

1. 경쟁사 12곳 비교 결과: 지구본+타격+코리도+드론+AIS+BRI/DFC를 다 가진 곳이 없다는 게 확인됨 → 레이어 조합 자체는 자산.
2. 그런데 "정보력이 얕다"는 자체 진단 → 폭은 넓은데 개별 레이어 깊이·신선도·검증이 약함.
3. "전세계를 다 깔아야 하나" 질문 → 아니오. CRINK 스코프 밖(아프리카·대부분의 남미)은 실측 데이터를 쌓을 이유(연결될 코리도)가 없음. 대신 전세계 배경은 Natural Earth 같은 가벼운 레이어로, 정밀 처리는 CRINK 관련국에만.
4. 이 질문 자체가 "타깃이 안 정해졌다"는 더 큰 문제의 증상이라는 게 드러남 → 타깃을 좁히기로 함.
5. 좁히는 방향을 CRINK축/우크라이나OSINT/애호가종합 3안으로 제시했으나, 사용자는 그중 하나를 고르는 대신 **"지정학과 지경학 각각 뭘 보여줄지부터 구조를 잡자"**를 선택.

## 2. 이미 코드에 절반 있던 것 — 새로 짓는 게 아니라 완성하는 일

`GlobeDashboard.tsx`에 이미 **"이코노미 모드"** 토글이 존재합니다. 다만 저번 UX 감사에서 "이코노미 모드로 바꿔도 지정학 전용 범례가 그대로 남는다"는 버그가 지적됐습니다 — 즉 지정학/지경학을 나누겠다는 시도는 이미 있었는데 완성되지 않은 채 방치된 상태였습니다.

더 결정적으로, **CRINK 축 네트워크의 관계유형(`AXIS_RELATION_COLORS`)이 데이터 모델 차원에서 이미 두 축을 나눠놓았습니다**:
- `arms`(무기이전) · `patronage`(후원) · `diplomatic`(외교) → 지정학
- `energy`(에너지) → 지경학
- `hybrid` → 애매함, 별도 결정 필요

즉 "이코노미 모드"를 energy만 남기고 arms/patronage/diplomatic을 숨기는 필터로 완성하면, 축 네트워크 하나로 두 모드를 자연스럽게 지원할 수 있습니다.

## 3. 콘텐츠 매핑 (시장 리스크 지도 — 2026-09)

| | 지정학 — 누가 누구와 싸우고 동맹하는가 | 지경학 — 막힘이 시세에 닿는가 |
|---|---|---|
| **간판** | **GTS** + **제재 회피 강도**(칩·회랑·위장선박) | **GSCPI · 해운 프록시 · PortWatch** |
| **첫 화면** | 전선·NEPTUN·항모·기지·GDELT war | **초크 · 항로 · 항구 · 가스/LNG · 무역 코리도 · energy/결제 축 · 이란 유류 NewFeeds** |
| **수동 토글** | ADIZ·축 군/대리 hybrid 등 | BRI/DFC · 송유관 · 민간 AIS · 제재 명단 · AI DC · 핵심노드 |
| **넣지 않음** | BRI/DFC | 전선·군함·제재 회피 강도 칩·회랑(지정학 전용) |
| **게임화** | GTS 감각 연습·벙커 | — (해석·딥링크만, 주문·추천 아님) |

**지경학 Job:** 초크/에너지/물류 충격을 지도에서 읽고 → 관련 선물·지수(티커·허브)로 이어 주는 **개인용 시장 리스크 터미널**.

## 4. GTS 신뢰성 (지정학 기축 — **대부분 반영됨**)

- **이름:** UI 티커 **GTS** (Global Tension Score). IEP Global Terrorism Index(GTI)와 명시적 구분.
- **설명:** 20대용 줄글(`gtiMethodologyProse`) → 출처 패널 상단; 산출식은 접기(`gtiMethodologyCopy`).
- **드라이버:** 전장별 “최근 90일 평균보다…” (`tensionDrivers` + DailyRankSharePanel) — 유지.
- **게임:** 감각 연습 톤. 지수 신뢰 = 게임 재미의 전제.
