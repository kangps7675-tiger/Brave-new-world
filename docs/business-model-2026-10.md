## 0. 한 줄 결론

**팔 것은 "지도"가 아니라 "한 사건을 공간적으로 입증한 결과물"이다.**
처음 6개월은 구독 SaaS가 아니라 **건당 제작(서비스)으로 수요와 반복 패턴을 찾고, 반복되는 것만 제품·구독으로 올린다.**

```
Stage 0   건당 증거 패키지 (수작업, 본업 병행)      ← 지금 시작 가능
Stage 0.5 교육·워크숍 ("뉴스 단신을 지도로 입증하기")  ← 웹 조사상 OSINT 분야에서 실제로 돈이 되는 축 (§0.5)
Stage 1   크리에이터 셀프서브 구독                  ← Stage 0/0.5에서 반복된 작업만
Stage 2   팀/뉴스룸 플랜 (좌석 + 공유 + 감사 이력)   ← 요청이 오면
Stage 3   임베드·API·데이터 라이선스                 ← 라이선스 정리 후
```

> **개정 (웹 조사 반영):** 이 분야에서 실제로 돈이 확인되는 곳은 "도구 구독"이 아니라 **사람의 신뢰·기술을 파는 것(교육·분석·제작)** 이다. 도구는 그 위의 레버리지로 둔다. 근거는 §0.5.

### 읽어야 할 것

1. **이 분야에서 확인된 가장 큰 현금 흐름은 "교육·워크숍"과 "재단"이다.** Bellingcat은 도구 구독이 아니라 사람을 가르치고 후원을 받아 운영된다. 사용자 0명의 1인 프로젝트에는 도구 구독보다 **교육이 더 빨리 현금이 되고 신뢰도 쌓는다.**
2. **구독이 되는 곳은 "도구"가 아니라 "분석(판단)"** 이다. GPF·Stratfor는 개인에게 연 $79~99 수준, 기업에는 협의가를 받는다. 대규모 현금(Dataminr)은 **기업·정부**에서 나오며 뉴스룸은 작은 조각이다.
3. **GeoGuessr는 우리와 가장 닮은 비용 구조**다. 지도 API 비용이 무료 모델을 무너뜨렸고, **크리에이터가 성장 엔진**이었으며, 유료화에는 **반발**이 따랐다. 지금 설계한 "3D는 유료 전용"과 같은 결정을 이미 겪은 사례다.
4. **Flightradar24는 해자의 원천이 다르다.** 자체 수신망(= 자체 데이터)이 있어서 광고·구독·B2B가 전부 붙는다. 우리는 공개 데이터를 모으는 구조라 **같은 모델을 복제할 수 없다.** 따라서 "자체 데이터"에 해당하는 것(§7의 일별 이력, 사건 파일)을 만드는 게 장기 과제다.
5. **솔로 창업자의 흔한 경로는 "서비스 → 제품"** 이다 (Castos 등, 자기보고). 단 "서비스 사업자가 소프트웨어로 넘어가 성공하는 비율은 낮다"는 경고도 같은 조사에서 나왔다.

### 추천 조합 — "신뢰 → 현금 → 제품" 순서

```
[0~3개월]  A 교육 파일럿 1회 + B 건당 제작 3~5건 + E 보조금 1건 신청
              → 얻는 것: 현금 소액, 후기, 사례(포트폴리오), 반복 패턴, 이메일 목록
[3~9개월]  C 무료 브리프 발행 → 유료 분리  /  D 반복된 작업만 셀프서브화
[9개월~]   코호트 재모집 + 도구 구독이 교육 수료자·크리에이터를 흡수
```

**왜 이 순서인가:** 사용자 0명에서 도구 구독부터 만들면 (a) 개발 비용, (b) 라이선스 불확실성, (c) 청중 부재를 한꺼번에 떠안는다. 교육·제작은 **셋 다 작다.**

### 조사에서 못 찾은 것 (빈칸)

- **크리에이터·기자가 지도 장면에 지불하는 단가.** Fiverr 등 지도 애니메이션 판매 페이지는 있으나 가격이 숨겨져 있거나 견적제다. Stage 0 가격(₩5만~50만)은 **여전히 근거 없는 가설**이다.
- Bellingcat **온라인** 워크숍 가격 (대면 €3,200만 확인). 온라인 코호트 가격은 가설(₩20만~60만)로만 둔다.
- 솔로 OSINT 뉴스레터의 **실제 구독자·전환·가격.**
- 한국 시장 데이터 일체.
- OTF, Prototype Fund, Knight, Google News Initiative의 **현재 공모 상태**(이번 검색에서 미확인).

## 4. 가치 제안 — "사건 → 증거 → 변화 → 공유"

북극성 흐름과 **이미 구현된 것**을 대조한다 (코드 확인 기준).

| 단계 | 사용자가 하는 일 | 이미 있는 것 | 비어 있는 것 |
|---|---|---|---|
| **사건** | 뉴스 단신에서 장소·시점 추출 | `/api/cases/extract`, `/api/cases/investigate`, 뉴스 스트림, 사건 파일 | 단신 → 후보 장소 **자동 지오코딩 품질** (실측 필요) |
| **증거** | 위성·3D·사건 레이어를 겹쳐 입증 | Cesium 관측 모드, `CaseEvidenceAttachBar`, `EvidenceTier` 등급, GIBS/Sentinel 계열 | 증거 **타임라인 비교(전/후 슬라이더)** 의 완성도 |
| **변화** | 이전/이후, 시간 경과 | `case_revisions` 수정 이력, 일별 시계열 테이블 | 위성 전후 비교 UI |
| **공유** | 이미지·영상·링크로 내보내기 | `captureShareImage`, `cesiumRecordClip`, `sceneLink`(`?scene=`), `sceneCard` | **워터마크·출처 자동 표기·패키지 내보내기(ZIP/PDF)** |

핵심 관찰: **"공유"와 "증거 이력"은 상당 부분 구현돼 있다.** 비어 있는 건 "결과물을 *납품 가능한 형태*로 묶는 마지막 한 걸음"이다. 이게 Stage 0의 제품 요구사항이다.

현재 `ObservePaywallOverlay`(Cesium 관측 30초 미리보기 → 잠금)는 **②에 직접 대응**하므로 이 BM에서는 방향이 맞다. 단, 지금은 `localStorage` 플래그라 서버 판정으로 바꿔야 한다.

## 6. 가격·단위경제 설계 원칙

1. **가격은 "대체하는 비용"에 닻을 건다.** 크리에이터가 외주 모션/수작업에 쓰는 시간·돈이 기준이다. "지도 구독료" 비교를 피한다.
2. **무료 티어는 원가가 상한이 있어야 한다.** LLM·3D가 무제한 무료면 사용자가 늘수록 적자다.
3. **초기에는 구독보다 크레딧(선불 N회)이 낫다.** 본업 병행이라 가끔 쓰는 사용자가 많고, 구독 해지율이 높을 가능성이 크다.
4. **연간 할인은 Stage 2부터.** 사용자 0명 단계에서 연 계약은 의미 없다.

### 6.1 웹으로 확인한 가격 기준선 (2026-10-11)

| 제품 | 플랜 | 가격 | 우리에게 주는 신호 |
|---|---|---|---|
| **Datawrapper** (기자용 차트/지도) | Free / Pro / Business | $21 / **$39** per user·month | 게이트 축이 "데이터"가 아니라 **PNG 무료 → PDF/SVG·출처표기 제거·이력 보존**. 우리 Creator 플랜 설계와 같은 구조 |
| Datawrapper | 커스텀 테마 애드온 | +$499/월 | 브랜딩은 별도 고가 SKU |
| Datawrapper | API | 크레딧 종량(생성 $0.04, 게시 $0.02, 내보내기 $0.01), 2026-10-01부터 과금 | API는 **정액이 아니라 연산 단위 종량** |
| **Felt** (협업 지도) | Team | **$200/월 정액**(연간) · 에디터 3명 · 25인 | 팀 플랜은 **좌석당이 아니라 팀 정액**이 통용 |

| **World Monitor** (직접 경쟁) | Free / Pro / Pro Business / API | $0 / **$39.99** / **$49.99** / $99.99~$299.99 | 대부분의 레이어가 **무료**. 유료는 AI 분석·내보내기·API. **"개인 라이선스 vs 상업 라이선스"를 별도 SKU로 분리** |
| Liveuamap (2차 출처, 미검증) | API Pro / Enterprise | $150/월(200 req/일) / $1,000~/월 | 데이터 API는 월 $150~1,000대 |
| Cesium ion | Commercial / Premium | $149 · $524(팀) / $499 · $874(팀) | §6.2 고정비 하한 |

**읽는 법**
- 경쟁 가격대는 **$21~50/월/사용자**가 중심이다. 초판의 ₩9,900~19,900(≈$7~14)은 **너무 낮을 가능성**이 높다. 낮은 가격은 지원 부담 대비 수익이 안 나온다. 개정 가설: **Creator ₩19,000~29,000 / Pro ₩39,000~59,000**.
- World Monitor가 보여 준 구조 — **같은 기능에 "개인용"과 "상업용(고객 작업)" 라이선스를 가격만 달리해 분리** — 는 크리에이터에게 그대로 적용된다. 영상으로 수익을 내는 채널은 상업 라이선스 대상이다.
- 무료로 레이어를 다 주는 경쟁자가 있으니 **"레이어 접근"을 유료 축으로 쓰지 않는다.** 유료 축은 ① 내보내기 품질/워터마크 ② 사건 파일 이력·저장 ③ AI 조사 횟수 ④ 상업 이용권.

### 6.2 고정비 하한 (Cesium)

공식 요금표 기준: 상업 이용은 **Commercial $149/월(개인) · $524/월(팀)** 이 하한이고, 문구상 **"조직 밖에서 쓰이는 솔루션에 통합하려면 문의"** 이므로 외부 사용자에게 서비스하는 SaaS는 **Custom(협의) 대상**일 가능성이 높다. Google 3D 타일 쿼터는 Community 1,000 / Commercial 5,000 / Premium 10,000 root tiles/월이다.

- 환율 1,400원 가정 시 $149 ≈ ₩21만. **Creator ₩24,000 기준 유료 약 9명이 Cesium 고정비만 상쇄**한다 (LLM·인프라 제외).
- 따라서 **3D 관측 모드는 무료 티어에 전면 개방할 수 없다.** 현재 `ObservePaywallOverlay` 구조(미리보기 후 잠금)가 맞는 방향이다.
- 앱이 현재 Cesium ion을 쓰는지, Google API 키를 직접 쓰는지는 **코드/환경변수로 확인되지 않았다** (미확인).

### 단위경제 점검식 (숫자는 실측 후 채움)

```
기여이익/월/사용자 = 월 요금
                    − (LLM 호출수 × 호출당 원가)
                    − (3D·위성 사용량 × 단가)
                    − (렌더·스토리지·전송)
                    − (결제 수수료 ≈ 3~4%)
```

**출시 전 반드시 실측할 것:** 사건 파일 1건 조사에 드는 LLM 토큰·원가, 관측 모드 10분의 타일 사용량. 이 두 숫자가 없으면 가격 가설은 장식이다.

### 규모 감각 (산수일 뿐, 예측 아님)

| 유료 사용자 | 월 ₩14,900 평균 | 비고 |
|---|---|---|
| 30 | ₩447k | 인프라비 회수 수준 |
| 100 | ₩1.49M | 본업 병행 부수입 |
| 300 | ₩4.47M | 지원 부담이 본업을 위협하기 시작 |

**전환율을 모르므로 "무료 사용자 몇 명이 필요한가"는 계산하지 않는다.** Stage 0 결과로 채운다.

## 8. 성장 루프와 유통

### 8.1 구조적 루프 (제품에 내장)

```
크리에이터가 장면 제작 → 영상/게시물에 노출(워터마크 + ?scene= 링크)
   → 시청자가 링크로 같은 장면을 직접 탐색 → 일부가 자기 장면 제작 → …
```

- Free 티어의 **워터마크 + 원본 장면 링크**가 유일한 유료 광고다.
- `?scene=` 링크 방문자가 읽기 전용으로 바로 상호작용 가능해야 루프가 돈다 (이미 구조 있음).

### 8.2 초기 유통 (본업 병행 가능한 것만)

1. 지정학/국제 유튜버·숏폼 크리에이터 **직접 DM 20명** → Stage 0 첫 2~3건은 무료 제작(후기·포트폴리오 목적).
2. 제작한 장면 자체를 공개 게시 (결과물이 곧 영업자료).
3. 기자 커뮤니티/OSINT 커뮤니티는 **도구가 아니라 사례**로 접근.

### 8.3 하지 않을 것

- 유료 광고, 대규모 SEO, 앱스토어 — 사용자 0에서 의미 없음.
- 엔터프라이즈 영업, RFP 대응.

### 변호사에게 가져갈 질문 (초안)

1. 유료 구독 화면에서 데이터를 **그려서 보여주기만** 해도 CC-NC 소스는 상업 이용인가? 무료 티어 + 유료 전환 유도 구조는 어떤가?

3. Cesium ion 사용 시 최종 사용자에게 구독료를 받는 서비스의 요금제 구간은?

## 10. 90일 검증 계획 (본업 병행 기준)

### 중단/전환 기준 (사전에 정해 둔다)

- 주 3 종료 시점에 "수작업으로 한다"는 응답이 0~1명 → **타깃 세그먼트 교체**(기자 ↔ 크리에이터).
- 주 6 종료 시점에 무료 제작조차 재의뢰가 0 → 결과물 품질 또는 가치 가설 문제. **제품 확장 중단**.

| **쌓는 자산** | 사례, 후기, 이메일 목록, 원가 실측 | **12개월+ 이력**, 공개 방법론, 수료자 네트워크, 사건 파일 아카이브 | 브랜드 신뢰, 데이터 이력, 커뮤니티 |
| **핵심 위험** | 수요 없음 | **수작업 한계(본업과 충돌)**, 비용 구조 | AI 대체, 플랫폼 약관·비용 변화, 경쟁 |
| **비중** | 서비스 100% | 서비스 60→30% / 제품·교육 40→70% | 선택한 경로에 따름 |

### 15.2 단기 (0~6개월) — §10과 동일, 요지만

건당 제작 + 교육 파일럿 1회 + 보조금 1건 + 랜딩/인터뷰. **돈보다 반복 패턴과 단가 데이터를 얻는 게 목적.**

**지금 반드시 시작해야 하는 장기 투자 (눈에 안 띄지만 되돌릴 수 없는 것)**

| 항목 | 이유 | 현황 |
|---|---|---|
| 일별 이력 **끊김 없이** 쌓기 | 과거 데이터는 소급 불가. 오늘 빠진 하루는 영구 결손 (`convergence-track-record.md`) | 구조는 있음. **하트비트로 구멍 모니터링** 필요 |
| 사건 파일마다 **출처·증거 등급·수정 이력** 기록 | 나중에 "감사 가능한 조사"를 팔 수 있는 유일한 근거 | `EvidenceTier`, `case_revisions` 있음 |
| **이메일 목록** | 플랫폼이 바뀌어도 남는 유일한 청중 자산 | 없음 |
| **원가 계측** (조사 1건당 LLM·타일·연산) | 중기 가격·한도 결정의 전제 | 미측정 |
| 소스별 **라이선스 클린 경로** 확보 | 장기 선택지(API·임베드)의 전제 | 변호사 확인 대기 |

### 15.3 중기 (6~18개월) — "서비스에서 제품으로"

**왜 이 시기가 가장 위험한가:** 서비스 매출은 본업 병행 시 **시간 = 매출**이라 한계가 곧바로 온다. 이 구간에 제품화가 안 되면 번아웃 또는 정체로 끝난다 (서비스 → SaaS 전환 성공률이 낮다는 조사 경고와 일치).

| 시기 | 할 일 | 게이트 |
|---|---|---|
| 6~9개월 | 반복된 작업 **1~2개만** 셀프서브화(예: 전후 비교 장면, 출처 표 자동 생성). 무료 브리프 발행 시작 | 같은 유형 의뢰 **3건+ 반복**, 수동 처리 시간이 건당 **절반 이하**로 감소 |
| 9~12개월 | 로그인 + 플랜 판정(`getEntitlements`) + 결제 도입. 유료 크리에이터 플랜 출시 | 유료 선결제 의사 표명 **≥10명**. 단위경제 점검식(§6)이 **양(+)** |
| 12~15개월 | 교육 코호트 정례화(분기 1~2회), 수료자 → 구독 연결 | 코호트 **재모집 충원**, 수료자 중 유료 전환 **≥1명** |
| 15~18개월 | 소규모 팀/뉴스룸 플랜 **요청이 온 건만** 대응. 이력 기반 "트랙레코드" 산출물 공개 | 팀 플랜 문의 **≥3건**. 12개월 이력으로 의미 있는 통계 산출 가능 |

**중기에 하지 말 것**
- 증시·신호 상품화 (인터뷰에서 선결제 의사가 나오기 전까지).
- 영업 인력 필요한 B2B 직접 영업.
- 레이어 확장 경쟁.

**중기 산수 예시 (예측 아님)**

| 구성 | 산수 | 월 매출 |
|---|---|---|
| 구독 50명 × ₩24,000 | 50 × 24,000 | ₩1.2M |
| 코호트 월 1회, 8명 × ₩300,000(가설) | 8 × 300,000 | ₩2.4M |
| 건당 제작 월 2건 × ₩150,000(가설) | 2 × 150,000 | ₩0.3M |
| **합** | | **약 ₩3.9M** (고정비 Cesium 등 약 ₩21만~ 차감 전) |

### 15.4 장기 (18개월~) — 세 개의 경로, 중기 증거로 선택

| 경로 | 모습 | 선택 신호 | 해자 | 대표 사례(웹 조사) |
|---|---|---|---|---|
| **P1. 교육·신뢰 브랜드** | 워크숍, 방법론, 소규모 구독, 후원·재단. 도구는 교재 | 코호트 충원이 빠르고 수료자 후기가 강함, 도구 구독 전환은 낮음 | **사람·평판·커뮤니티** | Bellingcat (재단 약 50% + 워크숍) |
| **P2. 크리에이터·뉴스룸 도구 SaaS** | 셀프서브 구독 + 팀 정액 + 임베드 | 구독 유지율 양호, 같은 도구 요청 반복, 크리에이터 유입이 링크로 확산 | **워크플로우·사건 파일 이전 비용** | GeoGuessr(크리에이터 견인), Datawrapper(계단식) |
| **P3. 이력·판단 데이터 상품** | 시계열·증거 등급·사건 DB를 API/라이선스로 제공, 기업·기관 대상 | 외부에서 "이 이력을 사고 싶다"는 문의, 이력이 12개월+ 끊김 없음 | **복제 불가한 시간 축 이력** | Dataminr(기업 중심), Flightradar24 B2B(자체 데이터) |

**선택 규칙 (사전 합의)**
- 18개월 시점에 **가장 증거가 강한 경로 하나에 자원을 몰아준다.** 셋을 동시에 하면 1인 체제는 무너진다.
- P3는 **라이선스 정리(§9)가 끝나기 전에는 선택할 수 없다.**
- 어느 경로도 증거가 없으면 **P0 = 취미/포트폴리오로 격하**하고 지출을 최소화한다 (실패가 아니라 정해진 결말 중 하나).

### 15.5 장기 위험 — 시간이 지날수록 커지는 것

| 위험 | 왜 장기적으로 커지나 | 대응 |
|---|---|---|
| **범용 AI가 "단신 → 조사" 흐름을 대체** | LLM·에이전트가 지도·검색·위성 도구를 직접 쓰면 워크플로우 자체는 복제됨 (이 항목은 웹 조사가 아니라 **내 추정**) | 해자를 워크플로우가 아니라 **출처 이력·감사 가능성·신뢰·커뮤니티**로 이동. 사건 파일의 "사람 검증" 표기를 상품화 |
| **플랫폼 비용·약관 변화** | GeoGuessr는 Google Maps 비용으로 모델 자체를 바꿨다. Google 3D 타일 약관은 공백이 많음 | 3D 의존 기능을 **교체 가능한 모듈**로 분리, 위성(Sentinel/GIBS) 경로를 기본으로 |
| **뉴스 사이클 의존(수요 변동)** | 분쟁이 잠잠하면 트래픽·구독이 떨어질 수 있다 (분쟁 수요의 변동성은 내 추정) | 사건 의존 상품(알림)과 **비의존 상품(교육·방법론·아카이브)** 을 섞음 |
| **무료 경쟁자의 기능 추월** | World Monitor는 레이어 대부분을 무료로 제공 | 레이어 경쟁 포기. 이력·증거·교육으로 차별화 |
| **데이터 소스 폐쇄·유료화** | 비공식 엔드포인트 의존(UKMTO 등) | 소스 이중화, 자체 큐레이션 비중 확대 |
| **1인 의존(키퍼슨)** | 시간이 지날수록 코드·운영 부채 누적 (`GlobeDashboard` 8,000줄 등) | 상태 분해(8b), 운영 자동화, 문서화. 중기에 **외주/공동창업자 검토** |
| **규제** | 투자 조언 오인, 유사투자자문업 등 | 증시는 읽기 전용 맥락만. 변호사 확인 |

### 15.6 장기적으로 모순되지 않게 해 두는 설계 결정

1. **사건 파일 포맷을 내보내기 가능하게** — 사용자가 이탈해도 데이터를 가져가게 두는 것이 오히려 신뢰를 만든다. 단 원본 소스 재배포는 §9 범위 내.
2. **방법론 공개** — 증거 등급·검증 절차를 공개 문서로. 교육(P1), 신뢰(P2), 데이터 판매(P3) **세 경로 모두에 필요한 공통 자산.**
3. **가격은 "작업 단위"** — 조사 1건·내보내기 1회·코호트 1회. 시장·AI가 바뀌어도 가치 단위가 유지된다.
4. **플랜·권한은 서버 판정** — 어떤 경로를 택하든 필요. 중기 초에 한 번만 제대로 만든다.

### 15.7 경로 선택에 쓸 지표 (6개월부터 기록)

| 지표 | 의미 | 어느 경로를 지지하나 |
|---|---|---|
| 코호트 충원율 · 후기 · 재참여 | 사람 신뢰 | P1 |
